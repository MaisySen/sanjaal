# Sanjaal

Nepali community app. Publisher: Fintex Australia Pty Ltd, ABN 60 688 406 108, contact@fintex.au.

- `api/` Laravel API (Auth0 token verification, feed, chat, media in Postgres)
- `app/` Flutter app (Android first)
- `sfu/` reserved for calls (not built)
- `docs/` releases and notes

Secrets live only in gitignored `.env` files and host settings. None are in this repository.
